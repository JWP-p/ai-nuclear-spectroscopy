# Roadmap

The roadmap favors scientific traceability over feature count.

## 0.1 — Transparent vertical slice

- [x] Public nuclear-data retrieval with provenance.
- [x] Source-local F-D-G cascade screening.
- [x] Count-statistics assessment.
- [x] Structured AI review and explicit human approval.
- [x] Synthetic four-region GCD demonstration.
- [x] PRD covariance and explicit uncertainty scope.
- [x] Tests, documentation, licensing, and release audit.

## 0.2 — Interoperability

- [ ] Pluggable experimental histogram adapter contract.
- [ ] ROOT/uproot example using fully synthetic histograms.
- [ ] Versioned JSON Schema for complete workflow records.
- [ ] More complete ENSDF continuation-record handling.
- [ ] Cross-platform reproducibility matrix.

## 0.3 — Independent validation

- [ ] Public benchmark fixtures with known synthetic truth.
- [ ] Blind agent-evaluation tasks and scoring rules.
- [ ] Alternative centroid estimators with documented failure modes.
- [ ] Systematic-variation runner for gates, backgrounds, and PRD choices.
- [ ] Independent-method comparison templates.

## Long-term direction

- Reusable, source-aware adapters for more nuclear-data and detector workflows.
- Community-maintained scientific-agent protocols that expose evidence and disagreement.
- Portable evidence packages that can be audited across laboratories and software stacks.
- Human–AI collaboration patterns that accelerate discovery while keeping scientific responsibility visible.

Roadmap items are intentions, not promises. No milestone removes the need for detector-specific validation and qualified human review.
