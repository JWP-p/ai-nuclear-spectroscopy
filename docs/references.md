# References and Upstream Guidance

The following official resources define the public data context used by this project. Check the current pages and the specific evaluation relevant to your analysis.

## NNDC and ENSDF

- [NNDC NuDat 3 Guide](https://www.nndc.bnl.gov/nudat3/guide/) — interface and nuclear-structure/decay-data context.
- [ENSDF citation information](https://www.nndc.bnl.gov/ensdf/citations.pdf) — evaluator and dataset citation information.
- [NNDC data citation guidelines](https://www.nndc.bnl.gov/content/citgl.pdf) — guidance for citing NNDC-served data.
- [NNDC evaluated-data releases](https://www.nndc.bnl.gov/endf-releases/) — dated evaluated-data release context. ENSDF users should cite the applicable ENSDF evaluation or database version rather than treating this page as a substitute.

## Software and repository governance

- [GitHub: Licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) — why an explicit license matters.
- [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0) — license text and terms.
- [Citation File Format](https://citation-file-format.github.io/) — `CITATION.cff` specification.

## Method references

No method paper is bundled or silently claimed as the source of every detector-specific convention. Users should cite the GCD, fast-timing, detector-response, calibration, and analysis literature actually used by their experiment. A future contribution may add a curated bibliography after rights and applicability are reviewed.
