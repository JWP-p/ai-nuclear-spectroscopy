# Third-Party Notices and Data Boundaries

The core package uses only the Python standard library. Optional dependency groups are declared for development, YAML support, ROOT-compatible file access, and model-provider integration; those packages retain their own licenses.

This repository does not redistribute NNDC/ENSDF database records, journal articles, experimental event data, figures, detector calibrations, or third-party prompts. The bundled ENSDF-style file is fictional and was created for software testing.

When using public nuclear data, cite the relevant evaluator, publication, or dated database release in accordance with the data provider's guidance. When adding a dependency or third-party asset, document its source, version, license, and redistribution terms before merge.
